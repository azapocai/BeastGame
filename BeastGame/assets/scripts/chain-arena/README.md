# Chain Arena Cocos Demo

这是从网页原型迁移的 Cocos Creator 3.8.8 锁链缠绕专项测试版本：单一铁球锁链房、3 名普通敌人。

- [`../../../docs/PROJECT_DESIGN.md`](../../../docs/PROJECT_DESIGN.md)：项目定位、设计原则、技术基线与路线图。
- [`../../../docs/DEMO_STATUS.md`](../../../docs/DEMO_STATUS.md)：当前 Demo 的真实功能、参数、限制与验证记录。
- [`../../../docs/CHAIN_REWRITE_IMPLEMENTATION.md`](../../../docs/CHAIN_REWRITE_IMPLEMENTATION.md)：当前运行架构、硬性规则、性能预算、严格测试与编辑器验收清单；与旧方案冲突时以此为准。

## 启动

1. 用 Cocos Creator 3.8.8 打开 `BeastGame`。
2. 打开 `assets/MainGame.scene`。
3. 确认场景节点已经挂载 `GameBootstrap.ts`。
4. 点击预览。`GameBootstrap` 会在运行时创建 Canvas、图形、HUD 和全部玩法节点。

## 控制

- `WASD` / 方向键：移动
- 鼠标：瞄准；左键或空格 / `J`：攻击
- `Shift` / `K`：闪避
- `C`：专项测试强制拉脱；有普通接触时直接眩晕玩家端第一个接触，无接触时仍播放同链回直；回直扫中的普通敌人也会眩晕
- `R`：重开锁链缠绕实验场
- `F2`：显示锁链长度、动态锚点和有效直线路径
- 触屏：左侧拖动移动，右侧上半攻击，右下闪避

## 当前范围

- 当前测试范围：单房间、3 名普通敌人、减速移动、同范围近战、眩晕穿透、铁球实体碰撞、最多 4 个有序局部接触、满张力绊倒、释放扫掠命中和标记单位的链条反向影响；伤害与死亡关闭。
- 当前实现：`ArenaMotionResolver` 是铁球房玩家位置的唯一提交者；`ChainSimulation` 用固定 24 个节点统一碰撞、接触、局部绕角、张力、眩晕和绘制路径。旧 `ChainSnareSystem` 及其配套模块、测试已经删除。
- 当前张力：自由区间按最短直线、真实身体接触区间按绕体长度计入最低有效路线；铁球链长 317，黄色与自动滑脱统一使用 98% 满张力门槛。
- 当前表现：`ChainVisualDynamics` 用固定 16 节点只做纯显示采样；玩家移动时立即贴合权威路径，不保留锁链跟随惯性。场地、玩家、敌人、铁球、桶和链节共享 512×512 运行时 RGBA 图集与固定 Sprite 池，不再依赖 SVG。按当前范围不增加松链、接触、正向缠绕或反向解绕的专属效果。
- 当前已知限制：已通过 TypeScript 与纯逻辑测试，尚待 Cocos 编辑器复验实际操控、多人接触和 C 同链收紧表现；微信真机性能尚未验证。
- 滑脱附带命中：自动滑脱结算有效圈内候选；自动滑脱与 C 的原链收紧使用连续扫掠碰撞，路径中目标会绊倒、路径外目标不会受影响。
- 审核后基线：敌人碰撞先结算、玩家/铁球最后提交；绕体占用量扣减未来向外余量；圈内候选需稳定两次发布；主链与滑脱均有 AABB 宽相位；眩晕碰撞在 0.18 秒内渐进恢复。
- 本轮不开放：转盘、火药桶、多房间流程；后续再恢复这些验证项。

## 锁链规则摘要

- 单一权威：`ArenaMotionResolver` 是铁球房玩家最终位置的唯一提交者；`ChainSimulation` 是锁链玩法唯一权威；`ChainVisualDynamics` 与 Sprite 渲染只消费路径快照，绝不反写玩法。
- 普通敌人可接触链条、被缠绕和眩晕，但绝不能借链条拖动玩家或铁球。自动眩晕必须同时满足：当前身体接触局部绕角至少 45°、玩家主动同向绕行证据、有效张力至少 `CHAIN_FULL_TENSION = 0.98`。玩家回走释放张力时，黄色链条和自动滑脱资格同帧解除。
- 张力不使用 PBD 折线总长：自由链段按端点最短直线计长，只有当前真实接触敌人的区间保留绕体长度。松弛链形不能保留满张力或黄色状态。
- `IronBallTether` 是可移动锚点：仅当玩家在有效链长上限继续向外移动时，链条才能拖动铁球并给予受拉惯性；向内移动只释放张力。铁球受场地边界阻挡后，才裁剪玩家剩余越界位移。固定柱子与转盘锚点不允许被链力平移。
- `tetherInfluence` 标记单位可反向拖动玩家与可移动铁球，并使玩家摔倒；同时免疫自动眩晕、C 直接眩晕、圈内共享和回直扫掠等全部锁链眩晕入口。当前场内 3 名敌人均为普通单位。
- C 的回直复用原有 24 个规则节点，不创建第二条链；自动滑脱可影响同一有效圈内候选，C 与自动滑脱的回直扫掠只眩晕真实命中路径的普通敌人。
